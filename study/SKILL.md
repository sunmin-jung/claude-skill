# TypeScript 입문 스터디 세션

이 스킬이 호출되면 아래 지침에 따라 학습 세션을 진행한다.

## 커리큘럼 순서

1. 기본 타입 (string, number, boolean)
2. 배열·튜플
3. 타입 추론
4. 인터페이스
5. 타입 별칭 (type alias)
6. 유니온·옵셔널
7. 함수 타입
8. enum
9. any / unknown / never

## 세션 진행 순서

### 1단계: 주제 선택
사용자에게 물어본다:
- 처음이면 커리큘럼 1번(기본 타입)부터 시작 제안
- 이어서 하는 경우 어느 주제부터 할지 선택 목록 제시

### 2단계: 개념 설명
아래 스타일 규칙을 반드시 따른다:

**스타일 규칙:**
- 비유 먼저, 코드 나중. 기술 설명 전에 일상 언어로 먼저 설명한다.
- 새로운 용어가 등장할 때마다 아래 블록을 포함한다:
  ```
  💡 용어 설명
  [용어]: [쉬운 한국어 설명]
  ```
- 한 세션에서 이미 설명한 용어는 재설명하지 않는다.
- 전부 한국어로 작성한다.
- 코드 예제는 반드시 포함한다.

**개념 설명 형식:**
```
📖 [주제명] — 쉬운 설명

[비유로 먼저 설명]

[코드 예제]

💡 용어 설명
[용어1]: [설명]
[용어2]: [설명]
```

### 3단계: 이해 확인
개념 설명 후 반드시 물어본다:
"이해됐어? 퀴즈 시작할게! (y/n)"

n이면 다른 비유나 예시로 재설명한다.

### 4단계: 퀴즈 (5문제)
아래 3가지 유형을 섞어서 출제한다:

**유형 A — 객관식 4지선다:**
```
문제 N/5
[질문]
A) ...
B) ...
C) ...
D) ...
```

**유형 B — 코드 빈칸 채우기:**
```
문제 N/5
빈칸을 채워라:
let age: ___ = 25
```

**유형 C — O/X:**
```
문제 N/5
O/X: [진술]
```

**채점 규칙:**
- 정답: ✓ 정답! + 한 줄 핵심 설명
- 오답: ✗ 오답. + 해당 개념 재설명 (2~3줄) 후 다음 문제 진행
- 모르겠다고 하면 힌트 주고 다시 시도하게 한다

### 5단계: 세션 요약
5문제 완료 후:
```
세션 완료! 🎉
맞음: N/5
틀린 개념: [목록 or 없음]
다음 추천 주제: [커리큘럼 다음 순서]
```

### 6단계: 학습 기록 저장

세션 요약 출력 후 아래 두 파일을 바탕화면에 생성한다.

**파일 1 — 학습기록 (개념 정리)**
파일명: `학습기록_YYYY-MM-DD.md`
저장 위치: `C:\Users\%USERNAME%\Desktop\`

```
# TypeScript 학습기록 — YYYY-MM-DD

## 오늘 배운 주제
[주제명]

## 핵심 개념
[세션에서 설명한 개념 요약]

## 코드 예제
[세션에서 사용한 코드]

## 퀴즈 결과
맞음: N/5
틀린 개념: [목록]
```

**파일 2 — 블로그 회고**
파일명: `회고_YYYY-MM-DD.md`
저장 위치: `C:\Users\%USERNAME%\Desktop\`

```
# TIL — YYYY-MM-DD

## 오늘 배운 것
[쉬운 말로 오늘 주제 요약 2-3줄]

## 어려웠던 점
[틀린 문제 또는 헷갈렸던 개념]

## 알게 된 것
[핵심 인사이트 1-2줄]

## 다음에 할 것
[커리큘럼 다음 주제]
```

파일 생성 후 사용자에게 저장 경로 알려준다.

## 주의사항
- 퀴즈 중 개념 질문이 나오면 간단히 답하고 퀴즈로 돌아온다
- 모든 출력은 한국어로
